# ASTRA V5 — تقييم V4 وخطة التطوير (ما أُنجز وما لم يُنجز)

> الأساس: الأرشيف `RAS-EGX-ASTRA-V4` بالإصدارين `bc3a455` (الأحدث) و`489286d`. **لم يُعدَّل الأصل**؛ V5 نسخة منفصلة.

## 1) تقييم V4

| المحور | الحكم | الدليل |
|---|---|---|
| الحوكمة والسلامة | **قوي جداً** | تسليم ذري ببصمة SHA، رفض عند عدم محاذاة الجلسة، صلاحيات تنفيذ مغلقة، سياسة ترقية (30 جلسة / 30 صفقة / 90 يوماً / PF ≥ 1.2)، حماية معايرة الاحتمال، 5 workflows، 8 سكربتات اختبار كلها تنجح |
| جودة البيانات التاريخية | **ممتازة** | مطابقة **11,802 صفاً** مع بياناتنا المستقلة بإغلاقات متطابقة 100%، و177 صفاً صالحاً لجلسة 1/10 |
| القيمة الإحصائية (الألفا) | **غير مثبتة** | المحلل الأصلي أوزان يدوية (زخم 30% / اتجاه 30% / سيولة 20% / تذبذب 20%) بلا أي اختبار تاريخي؛ المحرك الألفا الحقيقي `TFE_V20_FUSION_RC2` خارجي ويعمل بوضع الظل فقط |
| المخرجات الفعلية | **لا توصيات** | سجل المتابعة: إدخال واحد، 0 مرشحين، 0 صفقات؛ الحوكمة محجوبة (مرجع V17 بتاريخ 2026-09-13) |
| هندسة الصفقة | **أهداف بعيدة** | وقف 1.5×ATR وأهداف 1.5R/2.5R/4R = 2.25 / 3.75 / 6×ATR، أي احتمال بلوغ منخفض بحكم التصميم |
| واقعية دفتر المتابعة | **متفائل** | الدخول يتحقق بمجرد لمس النطاق (لا فجوات افتتاح)، الوقف يُنفَّذ بسعر الوقف دون فجوات، ولا حد هبوط يومي |
| نظافة البيانات | **عيوب** | أسماء ملوثة بنصوص إعلانات في 211 من 213 صفاً، OHLC متوفر في 47% فقط من لقطة السوق اللحظية، واحتفاظ 60 جلسة فقط (لا يكفي لتدريب أو خصائص 60 يوماً) |
| النموذج الأساسي لديهم | **سلة متساوية الأوزان** (V16.9) | يتسق مع نتيجتنا أن انتقاء الأسهم لا يتفوق على السوق ككل في العينة الصاعدة |

**الخلاصة:** V4 بنية تسليم وحوكمة ممتازة تفتقد محركاً كمّياً مُتحقَّقاً. القرار: **الاحتفاظ ببنية V4 كاملة** وإضافة محرك كمّي مُختبَر كمسار بحثي/ظل (Quant Lane) يمر عبر نفس الحراس.

## 3) نتائج المحرك الكمّي على جلسة 1/10/2026 (خارج العينة، 108 جلسة)

- بلوغ الهدف 1: **66.5%** (كل الأسهم بنفس الخطة 61.7%) — الخطة نفسها تُنتج معظم النسبة.
- بلوغ الهدف 2: 38.0% (الأساس 27.2%). متوسط صافٍ للصفقة +0.76% (الأساس +0.37%).
- تفوق على السوق +0.39% للصفقة (نصف العينة الأول +0.57%، الثاني +0.21%). فاصل ثقة 90% للتفوق الإجمالي [−0.16%, +1.33%] **يشمل الصفر**.
- Placebo −0.53% إلى +0.38%: لا تسريب ظاهر.
- المحفظة: خطة الهدفين +11.9%، الاحتفاظ بالهدف البعيد +17.7%، متوسط السوق +27.9%.
- السوق **هابط** (اتساع 17.3%) ومفتاح الأداء الأخير مفعّل ⇒ كل المرشحين درجة C (مراقبة فقط).

## 4) ما لم يُنفَّذ (بترتيب الأثر)

1. **تاريخ أطول (5 سنوات)** لحسم هل التفوق حقيقي: `python quant/fetch/fetch_free.py --range 5y` من جهاز له إنترنت. أهم خطوة متبقية.
2. **جعل دفتر V4 الأمامي أكثر واقعية** (فجوات الافتتاح وحد الهبوط ودخول بالافتتاح) — تعديل `resolveCandidate` في `scripts/ucp-forward-ledger.js`؛ لم ألمسه كي لا أغيّر سياسة ترقيته.
3. **تدريب النموذج على هدف الخطة الجديدة** (الحالي مدرَّب على الهدف البعيد؛ الترتيب لم يتغير).
4. **مقارنة المسار الكمّي بسلة V16.9 وRC2** في نفس لوحة الأدلة.
5. **تشغيل الـworkflows على GitHub وVercel**: كتبتها واختبرت كل خطواتها محلياً، لكن لم أستطع تشغيلها هنا.
6. العطلات الرسمية: ضعها في `quant/config/holidays.json`.
